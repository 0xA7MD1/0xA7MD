## التسليم
**تم:** تنفيذ صفحة عربية RTL للبرمجة: تعريف، مشاريع، خبرات تقنية، نبذة، تواصل للتوظيف والمشاريع. نقل الثيم الأحادي والشعار المعتمد، وصورة تألق الأصلية 4672×3488 مع عرض عريض وتكبير عبر dialog. تألق امتداد Intlaq ورابطه مؤكد والريبو خاص. تثبيت dependencies من lockfile وإصلاح البناء. تحقق سطح المكتب والجوال 320 و390 بكسل دون تجاوز أفقي، الوضع الفاتح والداكن، التكبير وإغلاق Escape وإرجاع التركيز، التنقل والتواصل. HTTP للصفحة وOG والأيقونة 200، وصفحة غير موجودة 404. وثائق README وAGENTS وCLAUDE محدثة.
**باقي:** لا شيء في التنفيذ المحلي. نشر الموقع لم يُطلب.
**لازم تعرفه:** الشجرة متسخة قبل العمل وبها حذف مكونات وDATA. لا تسترجع/تحذف تعديلات غيرك. مصدر الثيم للقراءة فقط، وخطوط Thmanyah لم تُنسخ لقيد إعادة توزيع؛ البديل IBM Plex Sans Arabic. لا backend أو أسرار. فيديوهات RevuHub وAbdat تفتح على الطلب؛ تشغيل YouTube الخارجي نفسه لم يُؤكد. خادم المعاينة المملوك لهذه المهمة فقط على 3197؛ المنفذ 3100 لمهمة أخرى.

**التحقق النهائي:** نجح بناء الإنتاج وTypeScript وESLint للملفات المعدلة. المعاينات محفوظة في `../output/portfolio-preview/`. محاولة لقطة سطح المكتب الأخيرة قصّها مُركّب متصفح المعاينة رغم صحة أبعاد DOM، لذلك استُخدمت لقطة بحجم النافذة الافتراضي؛ فحص سطح المكتب السابق والجوال نجحا. خادم الفحص 3197 أُوقف. التعليمات الدائمة في AGENTS وCLAUDE متطابقة؛ هذا السجل سيُحذف بعد حفظه في git طبقًا لتعليمات أحمد.
