# inertia-scroll — تمرير GSAP المستمر

## ينتظر أحمد
لا بنود مفتوحة؛ أحمد طلب الاستكمال بعد عودة حد الاستخدام.

## التسليم
**تم:** ScrollSmoother مع ScrollTrigger، smooth 1.1 وsmoothTouch 0، هيدر خارج الغلاف، روابط الأقسام من API نفسه، إزالة التأثير عند reduced-motion. الإنتاج وTypeScript وESLint نجحت. المتصفح أثبت native720 بينما visual-15 ثم لحق إلى-700 (مع هامش20). الهيدر top16 ثابت. المشاريع استقرت قرب110px. إيقاف iframe بالكيبورد يعمل، body يتابع الارتفاع الجديد، الجوال390 بلا تجاوز، console بلا أخطاء.
**باقي:** بناء Git نظيف، رفع main، حذف السجل.
**لازم تعرفه:** ذاكرة الجهاز منخفضة؛ ESLint الأول نفدت ذاكرته ثم نجح مع max-old-space-size256. فحص IAB بالنقر فوق iframe اعترض إحداثيات كسرية؛ فحص الكيبورد نجح. wholePixels غير متوفر في أنواع3.15، جُرّب ثم أزيل. ملفات غير المهمة مستبعدة. توقف الأمر السابق قبل التنفيذ بسبب تعذر المراجعة الآلية عند حد الاستخدام، والآن عادت الأداة.
