# معاينات المشاريع — 2026-10-11

وافق أحمد على التنفيذ: كل مشروع يعرض صفحة الموقع الفعلية داخل إطار متصفح. المعاينة تستعمل viewport بحجم 1440×900 مصغرًا ليناسب الكارد؛ «تصفح المشروع» يبدّل إلى عرض متجاوب بالحجم الفعلي داخل الكارد. تتوفر إعادة التحميل، إيقاف التصفح وفتح الموقع مستقلًا.

IntersectionObserver يحمّل الإطارات قرب الظهور ويزيل البعيدة. ProjectList يسمح بتصفح مشروع واحد. قبل التفعيل لا تلتقط المعاينة النقر أو عجلة الماوس؛ بعده الموقع نفسه يعالج التفاعل. Escape يعمل من أدوات البورتفوليو؛ أحداث لوحة المفاتيح داخل موقع مختلف الأصل لا تصل إلى الصفحة الأم، لذلك زر الإيقاف ظاهر دائمًا.

الموارد هي موارد المواقع الحقيقية، وليست تكلفة صورة. التحميل عند الاقتراب يحد الاستهلاك لكنه لا يجعل التطبيقات خفيفة. لا يمكن إعطاء نسبة تباطؤ عامة دون قياس. لا backend أو بث متصفح أو حزمة إضافية.

فحص HTTP الحالي للروابط الستة أعاد 200 دون X-Frame-Options أو CSP يمنع التضمين. قد تتغير السياسة لاحقًا، وقد تتطلب أجزاء تسجيل الدخول أو فتح تبويب. لا نتجاوز هذه السياسات؛ رابط الفتح المباشر متاح دائمًا. onLoad ليس دليل نجاح محتوى موقع مختلف الأصل، ولا يمكن قراءة DOM الخاص به من البورتفوليو.
